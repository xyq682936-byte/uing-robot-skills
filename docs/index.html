READY TO TINKER

先选仿真平台，再聊三句。

第一次用，先告诉 agent 想在哪个仿真平台里玩。拿不准，就根据设备和任务一起选；已经选好的继续沿用。

  1. 抓什么？说个名字，丢个模型，或者说“找个没练过的试试”。
  2. 给多少次机会？每个物体试多少种策略，还是整批共用？你来定。
  3. 同时跑几台？想同时开几台就说几台；拿不准，先看看电脑能带多少。

没装所选软件？agent 会先询问是否需要协助下载和搭建，获准后再做。开跑前还会确认：成功几个不同策略后停止，以及本轮采用的验证标准。200 次 / 40 台是可选建议，不会自动开跑。

TRY · TUNE · TRY AGAIN

先抓住，再练顺，换个场景继续。

01 / EXPLORE

先试几种抓法

夹杯身、试杯把、换条接近路线。agent 看着新的反馈往下走，遇到问题再调整；每种抓法都要有实质区别。

02 / REFINE

抓住了，再练利索

等整批探索收尾，把成功的抓法拿出来复现。省掉空等和多余操作，再验证一遍，留下更顺手的版本。

03 / APPLY

换个场景，接着试

你想换个摆法、加点障碍，或者接着做下一步？带上已有经验去验证；卡住了，就围着具体问题继续探索。

UING · SIMULATION MODELS & DATA

折腾机械臂，
模型也得认真做。

杯把的孔、杯身的凹槽、夹爪能走的那条缝，都会影响一次抓取。我们也在整理这些物体的模型与数据，把几何、碰撞、动作和验证记录串起来，方便下一次接着试。

第一批是 23 件日常物体，有杯子、容器、玩偶，也有桌面小物件。原始包带有 USDZ、PLY、JSON 和参考图片，现已提供逐件下载和完整资产包；每件模型的质量和仿真适用性仍须分别检查。

发现模型有问题，就留好原件和备份，在得到授权后修副本，再放回仿真里验证。哪次用了哪个模型、哪种抓法、在什么条件下成功，都记下来。

模型和 SKILL，分开拿许可本 SKILL 下载不包含模型资产、训练轨迹或数据集。本次公开下载仅限固定 23 件原始模型；MIT 许可不覆盖模型与数据，也不额外授予商用、再分发或模型训练许可。

BEFORE YOU RUN

开跑前，把接口接上。

# 探索模式与操作经验积累

在未知物体、新操作任务，或已有策略实际抓取/操作失败后需要重新探索时读取。本技能当前执行范围仍为仿真；现实场景提供的问题可用于设定仿真任务，真实机器人运行另核对设备接口、现场约束与授权，不由技能更新自动启动。

## 通过现场反馈探索

探索模式的目的，是由 agent 根据真实交互反馈发现可行操作。确认已有资产、碰撞、接口、有效标准及必要控制边界后，直接进入有界的短段接近、接触与操作，边观察边调整；不把长篇策略文本、预造训练数据或完整固定轨迹作为开跑前置条件。当前并行所需的简短候选差异检查仍保留，不提前穷写整批动作。

用户在启动环节确定 X，默认建议仍为 40 台。同批 X 台采用 X 个经实质动作去重的探索策略并持续并行监管，按剩余预算、实际失败和停止条件推进，参见 [持续监管](parallel-runtime-and-demo.md#每批启动与持续监管) 和 [策略与预算](strategy-and-budget.md)。其他臂不必等待某一臂的分析结束。

每次关键反馈后，提出简短、可由下一段操作检验的假设，例如抓取部位不合适、进入通道受阻、接触未建立、姿态已变化或操作顺序有误；记录观察依据、拟做的有限变化、预期可观测结果与实际结果。假设与结论分开，不要求保存内部逐步思维过程。看到反例及时修正，不凭旧文字坚持继续；不为等待思考无限暂停全部机械臂。

## 失败后的模式回切

已训练物体仍可能在新姿态、环境或任务中失败。先核对新反馈、模型/碰撞、执行、接触及操作顺序，区分实际策略失败与接口/定位/监管故障。必要的技术恢复遵循既有有限上限；确认原方法不再适用或有实际操作失败需要新方法时，记录失败事件与适用条件，回到批量假设、直接反馈控制和不同策略探索，不反复播放旧成功轨迹掩盖失败。

回切保留物体历史、原成功范围和失败证据，不把物体重标“从未训练”，不清零原预算或自动新增 200 次机会。沿用仍有效的探索额度与 X；没有适用额度时明确待安排。失败后的新探索与已完成优化记录分开，不能借回切重新排入同一条已完成策略的优化队列。

[实际场景模式](actual-scene-mode.md) 失败后，先总结原策略的有效步骤、失败阶段和场景差异，再基于原策略开展针对性探索；保留有效部分，按证据决定是否扩大范围。这属于解决新场景适用性问题，不算重复复训，不清除原优化完成标记。新候选须在原失败场景及约定的完整任务中重新复核；成功后保存分支，不自动追加优化。

## 面向组合操作的经验

经验不限于单次夹起，可按已授权任务记录接近、接触、推移、转向、重抓、扶正、搬运、放置等操作片段及其关系。每个可复用片段保留任务意图、适用结构/设备、初始条件、接触与承力、关键反馈、动作边界、结束条件、失败/恢复条件和实跑证据；未知或未测试部分明确标记。

组合任务还要记录动作先后依赖、部件/物体身份与位姿、前一动作的实际结束状态是否满足下一动作条件，以及中间放置/重抓等状态变化。两个单项动作分别成功，不证明它们组合成功；新组合须在其有效环境和预算内实际验证，不拼接不同试次伪造一次完整操作。

长期目标是让用户通过对话表达任务，由 agent 结合现场感知、可检索的经验和本地控制接口探索未知交互及复杂组合操作。经验保存为带证据与适用范围的操作记忆，也可供其他 agent 检索、学习如何安排探索和执行；不保证未来任意任务可成功。共享给其他用户、上传或公开仍按已有数据授权处理。

[优化结果模式](success-replay-and-acceleration.md) 产出的成功方案用于后训练保存、操作建议和经验记忆。调用前核对当前条件，它不是对未知交互的固定答案；不因保存文档或复跑而声称神经网络参数已更新，或真实机器人能力已经验证。

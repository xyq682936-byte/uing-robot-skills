# 用户模型接入、评估与副本转换

用户提供新的物体模型、模型文件路径、对话附件或资产库软件入口时读取。本文件规定接入与转换流程；只修改规则不启动安装、转换或仿真。

## 入口与资产库对接

- 用户可以先用日常语言描述目标，再由 agent 结合已授权模型库、历史登记和当前任务定位；也可以直接提供名称、文件/目录路径、附件或资产编号。允许按 [启动信息](standards-and-setup.md#每次训练的启动信息) 处理“从未训练中选”或“继续”。能从已有记录找到可用资产时直接沿用，不要求用户重复填写路径；确无可访问入口或关键歧义未解时才协助确认。附件仅有名称但不可读取时说明缺口，不根据同名文件猜测或任意扫描个人目录。
- 用户使用资产库软件时，先确认软件、库或项目、目标资产身份与版本、访问权限和正式接口。阅读实际接口文档及库的单位、坐标、层级/依赖、版本、导出和使用规则；核对可用的查询、下载、导出格式及反馈，再接入和转换。不能只看到模型列表就声称已理解资产或接口已打通。
- 在授权范围内对目标资产进行有限读取/导出验证，保留资产编号、来源版本、接口结果和依赖清单。接口不可用时请求用户导出文件，不擅自改写资产库、底层数据库或绕过访问控制。除非另获明确要求，转换输出只进入本地副本库，不回写资产库原件。

## 先评估能否用于本轮仿真

对文件或资产库导出物先做一轮针对所选仿真环境及本轮任务的评估，至少检查以下适用项：

| 检查 | 判断内容 |
|---|---|
| 可读性与依赖 | 格式和版本支持，文件可解析；贴图、材质、外部引用及关联配置是否齐全 |
| 尺寸与坐标 | 单位、缩放、朝向、坐标轴、原点和变换关系是否明确且合理 |
| 几何与法线 | 网格有效性、法线/面朝向、退化面、洞/非流形及其对当前渲染或物理用途的实际影响 |
| 碰撞 | 是否有可用的碰撞表示；动态/静态物体所需碰撞类型、分解精度与接触区域是否适合本轮仿真 |
| 物理属性 | 刚体或关节定义、质量、重心、惯量、摩擦/材料、关节与驱动等本任务必需参数是否明确 |
| 场景与任务 | 模型复杂度、内存/显存开销、可加载性、所需传感器和测量接口，是否符合当前机器及验收配置 |

不是每种格式都必须在原文件中携带全部信息；明确哪些可由已确认的项目配置提供，哪些确实缺失。缺少法线、碰撞等问题要有实际检查依据，不把关键词缺失一律判为不可用。对纯渲染模型不能只看外观就判定可做物理训练。

评估结果区分“已具备本轮模型接入条件”“需要辅助转换/修复”“缺少必要资料”“当前环境不支持”，列出原因、影响、可处理项和待确认参数。已具备条件时直接沿用可用副本，不强制无意义地转换；软件、控制、标准、预算等其他运行条件仍须独立确认。

若不能直接用于本轮仿真，例如缺少有效碰撞、法线异常、格式不兼容或依赖不全，先向用户说明发现的问题及拟处理方式，询问是否需要辅助转换。用户同意后在明确范围内完成，不因用户上传文件就默认获准改动模型。已有明确转换授权覆盖的内容不重复询问；新增的物理假设或实质几何变化需要说明并获得相应依据。碰撞体误堵空隙另按下文专项询问执行，普通转换授权不替代该选择。

## 副本库与备份

在用户指定的数据/模型库根目录下增加以下分区；实际目录在接入任务中创建，不能把占位文字当作目录名称：

```text
用户指定根目录/
  用户模型文件复制/
    原始副本/<模型编号>/<导入编号>/
    备份/<模型编号>/<导入编号>/
    转换工作区/<模型编号>/<转换编号>/
    已转换好/<模型编号>/<转换版本>/
```

“已转换好”是“用户模型文件复制”的直接子文件夹。用稳定模型编号和唯一导入/转换编号区分同名文件与版本，不覆盖旧记录。已有等效库结构时在用户指定位置对接，不擅自迁移全部资产。

1. 原文件、原目录和资产库原件只读保留，不在其中修法线、生成碰撞、重写引用或保存转换结果。对话附件也以本地副本处理。
2. 获准处理后，先把模型及允许读取的必要依赖复制/导出到“原始副本”，保留相对引用与来源清单；计算源文件及依赖的大小和哈希，核对复制一致性。引用越出已提供范围时先说明所需依赖，不能顺带复制无关资料。
3. **复制完成后，再为这份副本建立独立、可读取的备份并校验一致性，之后才开始转换。** 备份不能是指向同一可变文件的快捷方式、软链接或硬链接；空间不足或备份失败时暂停转换，不跳过这一步。
4. 从已备份的原始副本生成独立“转换工作区”；修改只发生在工作区，不改源文件、原始副本或备份。转换器缓存、自动修复和引用重写也指向工作区，不能沿外部引用写回原件。
5. 记录源入口/资产版本、原始副本和备份路径及哈希、转换工具与版本、参数、修复项目、推导或用户提供的物理属性、输出版本和验证结果。失败保留诊断及可恢复副本，不以删除历史重来。

## 模型结构与碰撞修复

在已有转换/修复授权内只修改工作副本，按上节保留原文件、原始副本及独立备份。以下检查与修复针对当前模型、用途和仿真版本，不自动授权修改其他资产或启动训练。

1. 分别检查视觉几何与实际碰撞几何，识别生成、转换或碰撞简化造成的失真，包括孔洞被封堵、拉手孔消失、凹槽被填平、间隙被连接、薄壁被加厚，以及破面、法线异常和自相交。不能只看外观或只看水密检查结果。
2. 修复前区分物体本来具有的功能结构与生成模型产生的破损。开口、孔洞或边界缺口不自动等于错误，禁止为通过水密检查一律封口。对疑似误封的孔洞、通道和间隙，结合可取得的原始资料、参考图片、多视角模型及用户说明判断；证据不足标为待确认，请求缺少的依据，不猜测开孔、封孔或改造结构。待确认部分可隔离处理，不影响已有明确依据的其他检查。
3. 视觉几何正确而碰撞失真时，优先只修复碰撞模型；仅在视觉几何的误封或变形已被证实时修改对应几何，并同步更新碰撞。根据结构、刚体类型及所选引擎版本支持情况，核实并选择 SDF、合理凸分解或其他适用表示，不要求所有物体统一采用同一种方法。需要保留孔洞、凹槽或进入通道的区域，不得被整物体凸包或不合适的分解填实。
4. 除已确认需要修复的部分外，保持原有尺寸、比例、外观和物理参数。检查工具是否自动改变缩放、质量、重心、惯量或材料等设置；不接受未说明的连带改变。若修复确需变更关联参数，说明依据并按既有确认规则处理。逐处记录修改位置、原问题、判断依据、修复方法/参数及前后差异，保留可回退版本。
5. 修复后同时核对视觉结构、碰撞结构及实际加载采用的形状，不能只验输出文件。对相关孔洞、凹槽、间隙和进入通道，在已授权的有限原生仿真检查中验证必要的通行或接触响应，保留动作、实际接触和结果证据；未实跑或结果不明标为待验证，不能凭渲染画面或保存成功宣布修复完成。
6. 视觉上存在的真实开口，在碰撞层面也须保留相应空间和边界；这不保证任意夹爪都能进入。仍须按实际夹爪尺寸和姿态核实可达通道，不能为使夹爪通过而扩大孔洞、挖槽或减薄真实结构。验证不通过时区分碰撞仍失真、真实尺寸不匹配、控制/姿态问题和证据不足，不直接否定整个抓取部位。
7. 持久转换在相应授权内输出新的资产/碰撞版本并关联修复与验证证据；下节仅内存修正只登记运行版本和证据，不导出或回写修正后的资产。不在进行中的试次里静默替换模型。按既有规则核对旧策略和旧成功记录的适用性。模型修复验证单独标记，不冒充抓取探索成功或标准通过。

## 碰撞体误堵空隙的内存修正与询问

本节是已确认碰撞表示误填功能性孔洞、通道或间隙时的专项规则，适用于三种模式。它不授权改造真实结构；证据不足先标待确认。一般转换授权不能代替这里的专项选择。

1. 每次拟修正前，先说明误堵的几何证据、受影响物体/部位、计划修改的碰撞形状、仅在当前仿真内存生效、质量与摩擦保持以及修正前后分开统计，再给用户选择：**同意本次修正／本轮同类情况都同意／暂不修正**。未选择不默认同意；用户用文字表达同样明确的选择也有效。
2. “同意本次”仅覆盖所展示的修正事项；“本轮同类情况都同意”绑定当前稳定批次编号、明确的物体范围、同类有证据的误堵和仅内存修正条件。覆盖范围内仍逐项检查、登记并告知，但不重复询问。跨天、重启或对话恢复可核实后沿用同一未结束批次授权；本轮结束、用户撤销、范围改变或进入新批次时失效或重新确认，不能解释成永久授权。修正方法或参数要求超出已展示范围时重新询问。
3. 修正仅作用于已备份工作副本加载出的临时仿真实例/内存层，不保存回任何源资产、原始副本、备份或转换完成文件，也不把修正后的碰撞体导出成持久模型。可以保存授权、前后证据、运行碰撞版本标识和可复现的修改说明；记录不等于改写模型。引擎不能保证不回写，或需要持久转换时先说明限制并单独询问，不能用保存文件冒充仅内存修正。
4. 核对修正前后的质量、静/动摩擦及相关有效物理设置；保持尺寸、视觉几何、材料、重心和惯量等未获准改变的条件。不能因换碰撞表示触发自动重算后仍声称参数保持；无法保持或核实则停止采用该修正并说明，不暗改参数换成功。需要其他变化时另行说明与确认，不纳入“本轮同类都同意”。
5. 在受影响试次结束、受控暂停或复位边界应用，保留原始试次状态，不在一个验收窗口中途替换碰撞体。修正后核验实际加载形状及必要通道/接触；尚无实跑证据标待验证。只修已证实的误堵，不扩大真实孔洞、关闭必要碰撞或删掉承力结构。
6. 修正前、修正后的探索/验证次数、实际失败、成功、标准结果及统计分母分别按运行碰撞版本记录；保留原记录，不合并成同条件成绩，不把修正后通过描述为未修正原模型通过。诊断和模型修复验证另列，不冒充策略成功；同一策略跨版本复测不虚增独立策略数，修正与分组也不清零原预算或失败。
7. Trace 关联发现证据、询问及用户选择、授权范围/有效期、每次应用与回退、原资产哈希、运行碰撞版本、前后有效参数、验证和分组结果。仅内存修正不标为持久资产已转换完成；恢复运行时确认临时层是否仍存在，不能只凭旧授权或旧标记宣称修正已加载。


## 转换后复核与使用

- 转换应保持物品的真实几何、尺寸和已知物理特性。碰撞近似、网格修复或法线重建的方式与误差需记录，重点核对抓取接触区，按上节保留功能结构并修正已确认的生成/碰撞失真；不能为提高成功率改造真实接触外形或改变质量、摩擦、夹爪能力。未知参数不能填入未声明的默认值冒充实测。
- 输出后复查格式、依赖、单位/坐标、法线、碰撞与必需物理属性，并核对源文件、原始副本及备份未被改写。在已有运行/检查授权内做有限原生加载和必要物理响应检查；尚未获准或无法运行时如实标记未验证，不冒充可立即训练。
- 只有当前用途所需的转换及验证完成，才把该版本连同评估、转换清单和证据放入“已转换好”。未转换、转换中、失败和验证不足的版本留在各自区域，不能用目录名称掩盖缺口。
- “模型已转换并通过接入检查”不等于抓取成功、标准通过或整套训练环境已就绪。正式探索仍遵循用户所选标准、预算、停止目标及控制授权。模型版本变化须检查旧策略/结果的适用性；不能自动继承旧版本成绩。
- 直接可用的模型保留原始副本和备份，登记“无需转换—接入检查通过”，不为了归入“已转换好”而伪造转换记录。

此处的本地复制与转换不构成外传授权；成功数据是否上传仍按独立回传规则处理。

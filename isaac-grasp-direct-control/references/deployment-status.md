# 本地执行与上传接入状态

核对日期：2026-10-26。本文件说明 0.1.0 的实际边界，不能以部署记录代替用户电脑上的接入验证。

## 运行架构

技能规则、agent 决策及用户配置的仿真控制在本地执行。Uing 发布站不远程下发核心执行规则，不参与动作闭环。需要联网的 agent 服务取决于用户所选产品；本地执行不承诺大模型推理也在本机离线运行。

## 已有内容

- 可读的执行规则、模式引用和结构化归档要求。
- `scripts/success_upload.py`：成功数据契约第 2 版的本地结构检查、打包、队列和有限发送能力。它不自动从 Isaac 采集数据，也不验证真实物理成功。
- 接收服务具备产品与用户/项目隔离、文本贡献待评、成功文件隔离接收和发布签名能力；这些不是随 SKILL 安装到用户电脑的功能。

## 尚未完成的客户端接入

1. 按用户选定条目、修订、文件与用途限制发送队列的程序门禁。
2. 规则/策略贡献客户端。
3. 对成功包 `202` 待扫描回执的状态适配。当前辅助脚本会把该回执判为无效接收确认，不能称已上传成功或通过重复发送绕过。
4. 与具体仿真运行器的采集、归档及发送流程接入。

在这些接入及相应验证完成前，对 Uing 服务保持 `enabled=false`，配置不预填上传端点。授权缺失或功能不完整时保留本地记录，不影响已授权训练。不把通用 `scope`、上传令牌或过去分享过一次当作全量授权。

## 接收与证据含义

当前成功文件仅进入隔离待扫描区，不解析执行、不供普通用户下载或转为正式成功库。`stored=false` / `accepted_into_library=false` 表示尚未正式入库；隔离接收、扫描、格式校验和物理验证是不同状态。自动病毒扫描与自动五级评估未配置，文本贡献保持待评或按明确证据人工评估。

规则/策略原文、成功记录、公开展示、通用经验提炼与模型权重训练分别检查授权。发布服务器的可用性或维护状态不授予任何数据发送权限。

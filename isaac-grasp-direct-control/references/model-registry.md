# 以模型为入口的执行与验证管理

用户要求以模型区分未测试、已测试未成功、成功夹取待验证和已有验证通过策略，并可分别安排首次测试、失败追加、成功扩展和补验证。管理或交付模型清单时遵循本文件。

- 模型状态从带范围的执行和复核记录派生。没有资料不等于从未测试，历史不明标“记录待核对”。有试过但未成功的模型不能回到未测试。
- 一个模型可同时有通过、失败、待验证策略。“已验证”须注明模型版本、策略修订、判据与验证范围，并列出仍未完成的策略；不能泛化为所有抓法都通过。
- 按“模型 → 版本 → 批次 → 父策略 → 修订 → 机会 → 试次 → 阶段 → 证据”关联。每模型提供批次数、父策略编号去重数、已用机会、夹取结果、验证状态、策略表完整路径与原始证据入口。
- 编号去重不等于独立策略差异已核实。历史微调候选未完成去重时单列，不与新独立策略相加。
- 计划数量与实际执行数量分开。用户保存追加计划不代表已经派发或执行，不改写旧成功率、已用额度或失败记录。重复请求和重复导入按稳定编号去重；冲突报告拒绝覆盖。
- 失败追加用于新的有限探索；成功扩展用于寻找更多抓法；补验证复用成功策略并使用有限验证安排；中断恢复保留已完成部分和失败计数。分别记录预算和目标，不混成同一个“再跑”按钮。
- 用户追加新策略机会时，按 [追加去重核查](strategy-and-budget.md#追加机会的去重核查) 与同物品历史成功、失败、微调及当前队列比对。保存计划不代表去重通过；有差异证据的候选才可作为新增机会派发，旧策略重试与补验证另行标记，不能靠新计划编号重复占用新增策略名额。
- 为一次完整交付，在派发前确定测试矩阵、条件、记录与视觉入口、额度和停止规则；各臂按夹取核实、适用性能测试、复核与归档独立推进。不得等到运行结束才发现关键验收证据没有采集。
- 资产几何、质量、摩擦、夹爪能力、环境或判据版本变化后检查适用性。保留旧结果；不把旧版本成绩自动继承到新版本。仅文件入口哈希不能代表全部外部资产和物理配置一致。
- 执行记录、待复核报告、完整验证结论分别导入。结构校验和文件存在性检查不代替物理与视觉复核。无合格线的有效测量保持未评级。

## 工作模式与复训标记

探索模式、优化结果模式与实际场景模式分开登记，包含切换原因、源批次、父策略/修订、适用条件与预算。已训练物体实际失败需要新方法时按 [探索规则](exploration-mode-and-experience.md) 回切，保留原成功范围和失败史，不重标未训练，不自动给新额度。

优化状态按策略及适用范围逐项记录，不用物体级“已优化”遮盖其他未完成策略。按 [复训去重](success-replay-and-acceleration.md#空闲批量优化与完成去重) 统一关联源版本、优化产物与完成记录，选取前排除已完成和正在处理项。暂停恢复未完成部分，失败/证据不足显示原因；用户查询“还有哪些没复训”时给出可执行候选与被阻塞项的区别。界面标签及自动筛选尚需实现核实，不能凭文档宣称已接入。

实际场景记录按 [场景与失败分支](actual-scene-mode.md) 关联原策略及优化完成记录；新场景验证和针对性探索不是重复复训，成功/失败适用范围分别保留，不能用旧完成标签阻止新范围验证，也不清除标签后重新优化。仅内存碰撞修正登记运行版本及前后条件，不能标为持久模型已经转换完成。

## 自然语言选物与继续

用户可直接描述物体、给名称/路径/附件/资产编号，也可委托 agent 从当前已授权范围的未训练模型中挑选，或说“继续”。按 [启动信息规则](standards-and-setup.md#每次训练的启动信息) 将表达关联到已有稳定物体、资产版本和批次编号，不能因为没写专业路径就要求用户全部重填。

代选时查询真实执行记录，不能只筛“成功次数为零”；失败、待验证和历史不明与未测试分开。限定库/项目和批次规模，记录选择理由，不重新建库或删失败史。没有指定数量时先选一个候选，不自动开跑全部模型。“继续”关联明确未完成任务或已授权后续队列，读取剩余预算与恢复点；正在运行不重复启动，歧义或无可恢复记录再补问，不新增预算。

这些是行为与数据要求；自动检索、界面选择和恢复调度须核实实际接口是否实现，不能仅凭规则声称已接通。

## 用户模型来源与副本版本

新增用户模型先按 [模型接入与副本转换](asset-intake-and-conversion.md) 核实用户路径、附件或资产库接口，执行接入评估。登记来源资产/文件与依赖、原始副本、独立备份、转换工作区、已转换好版本的对应关系及校验信息。源文件不动，复制后先备份再转换；几何修复、碰撞近似和物理属性来源必须可追溯。

区分“无需转换且接入检查通过”“需转换”“转换中”“转换完成待验证”“转换及接入检查通过”，与抓取测试及标准状态分别记录；只有转换与必要接入验证完成的版本进入“已转换好”。管理界面登记或存在输出文件不能代替就绪验证，转换版本不自动继承原版本抓取成绩。

## 可选管理界面接入

使用用户已配置且已核实的模型库或管理接口；没有界面时使用现有配置和表格。界面状态须来自实际记录，不把待执行计划当作已运行，不凭登记成功宣布物理验证通过。

# Uing · 机械臂并行直接控制

> **首次使用，先选仿真平台。** 告诉 agent 想用哪个平台、有没有现成环境；还没决定，就结合设备和任务一起选。已有明确选择继续沿用，不默认把所有用户带到同一个平台。

> **开始训练前，先和 agent 确定三件事：抓什么、给多少次策略机会、同时跑几台机械臂。不用先学一套术语，像平时聊天一样说就行。**
>
> 1. **抓什么？** 描述物体，或提供名称、模型路径、附件、资产编号；也可以说“从未训练的物体里选一个”或“继续上次”。
> 2. **给多少次策略机会？** 说明每个物体的额度，或整批共用的额度。已有明确设置可以沿用。
> 3. **同时跑几台？** 告诉 agent 希望同步工作的机械臂数量；不确定时先让它根据设备能力提出建议。
>
> 示例：“从未训练的物体里选一个，每个物体给 200 个策略机会，40 台机械臂同时尝试。”示例数值不等于自动授权。

**安装：** 把下载链接或 ZIP 文件直接发给 agent，告诉它安装这个 SKILL，按提示完成首次配置即可。

**作者：Uing · 版本：`0.1.5` · 许可证：[MIT](LICENSE)**。许可范围为本独立发行的 SKILL、通用引用文档和配套代码，不包含模型或训练数据。

给 agent 一只手，在仿真里折腾起来。

找个物体，开几台机械臂，让 agent 试试不同的抓法。碰到了、滑了、抓住了——看反馈，改动作，把能复现的经验留下。

整批试完，再把成功的抓法练顺；你想换个场景时，就带着这些经验继续。

Uing 把这套做法整理成了供 agent 使用的 SKILL，配有本地成功数据打包与上传辅助脚本。仿真平台先由你和 agent 确定；当前控制流程围绕 Isaac Lab / Isaac Sim 整理，其他平台的接口与测量能力须先核实，不能只换软件名就当作已经适配。

## 先选仿真平台，再聊三句

首次先确定平台、版本要求和运行位置，再检查是否安装、依赖是否齐全、任务所需接口能否接通。缺少所选软件时，agent 会询问是否需要协助下载并搭建配套环境；说明方案并得到授权后再执行。已有环境和配置优先复用，安装完成还要核实能否开展本轮任务。详见 [环境选择与自动搭建](references/standards-and-setup.md#环境选择与自动搭建)。

不用填专业表格。说清你想试什么，agent 会结合已授权的模型库和任务记录补齐信息，缺什么再问什么。找不到模型就先找入口；说“找个没练过的”也不会把整个库都跑起来。“继续”沿用原任务剩下的机会，已完成的任务不会重启。

开跑前还需确定有效标准、每个物体成功 **K 个不同且已复核的策略**后是否停止探索，或者明确跑满额度。策略机会、实际失败次数和成功策略数分别统计；同时运行 X 台不自动把预算乘以 X。40 台、每物体 200 个机会、每机会最多 3 次实际抓取失败只是可调整建议。

## 先抓住，再练顺，换个场景继续

| 模式 | 何时使用 | 要保存什么 |
|---|---|---|
| 探索模式 | 未知物体、新操作，或已有抓法在当前条件下失败 | 不同抓取部位、接触关系与进入路径；现场动作、观测、失败依据和成功证据 |
| 优化结果模式 | 整批探索收尾并复核后，单独处理成功策略 | 基线复现、有限优化、重新验证和优化完成标记；避免反复复训 |
| 实际场景模式 | 用户调用既有策略，验证新的姿态、障碍或组合任务 | 场景条件、完整任务结果；失败后基于原策略进入有针对性的探索 |

模式切换和新增预算按当前授权处理。新场景失败后的针对性探索不算重复复训，但不会清除历史标记或自动获得新额度。

## 包里有什么，开跑还缺什么

- **通用执行规则与引用文档**：策略动作差异、多臂持续推进、失败分类、移动后重新定位、模型副本转换、性能监测、分阶段验证与归档。
- **本地辅助脚本**：按明确导出清单验证结构、打包、去重、保存队列及有限发送。脚本使用 Python 3.10 或以上及标准库。
- **配套合成测试**：位于源码仓库的 `tests/`，使用临时数据与本机回环；不控制仿真，不发送用户抓取数据。安装用技能包不附带开发测试。

开始仿真需要用户已有或经授权搭建的所选环境，以及实际可用的机器人控制、状态读取、调度、物理测量和证据导出接口。当前流程面向 Isaac Lab / Isaac Sim；其他平台须先核实实际适配情况，缺少接口或尚未验证时明确说明，不擅自换平台或承诺开箱即用。**本包没有附带通用机器人控制器、自动多臂调度器、物理验收器或一键安装器。** agent 必须检查这些接口是否接通，不能仅凭读到规则就报告功能已实现。

“训练”在这里主要指反馈驱动的探索与复现；不等于自动训练强化学习模型或更新大模型权重。仿真许可也不等于真实机器人运行许可。本轮成功只对实际验证的物体、条件、策略与标准范围成立。

## 动作在本地跑，数据由你做主

SKILL 和仿真控制在用户配置的本地环境运行，不从发布服务器远程加载核心规则，也不让服务器参与机械臂动作闭环。不分享数据不影响本地训练。

上传默认关闭。用户可选择少量新增规则、策略或指定成功试次；发送前展示条目、修订、文件类型与大小、接收方和用途，明确同意后才发送。不会因安装、使用或更新技能就上传全部历史或未来记录。

原始材料按授权保密，通用经验提炼只用于获准的版本改进；公开原始材料、模型权重训练分别需要对应授权。机械臂和夹爪身份、环境、判据、动作与观测证据按成功数据契约记录，不能只报成功标签。

**当前接入状态：** 辅助脚本尚未适配 Uing 接收服务的 `202` 隔离待扫描回执，也未实现逐条选择授权门禁及规则/策略贡献客户端。本版本保持上传关闭，不把后台已部署当作客户端已经可用。成功文件接收后仍需扫描与审核，不能把隔离接收解释为正式入库或物理成功。具体见 [接入状态](references/deployment-status.md)。

## 折腾机械臂，模型也得认真做

杯把的孔、杯身的凹槽、夹爪能走的那条缝，都会影响一次抓取。我们也在整理这些物体的模型与数据，把几何、碰撞、动作和验证记录串起来，方便下一次接着试。

第一批是 23 件日常物体，有杯子、容器、玩偶，也有桌面小物件。原始包带有 USDZ、PLY、JSON 和参考图片，现已提供独立的逐件下载和完整资产包；每件模型的质量和仿真适用性仍须分别检查。

发现模型有问题，就留好原件和备份，在得到授权后修副本，再放回仿真里验证。哪次用了哪个模型、哪种抓法、在什么条件下成功，都记下来。

**模型独立下载，不放进 SKILL 包。** [查看 23 件资产与逐件下载](https://43.110.149.187/models)，或 [下载完整资产包（约 218 MB）](https://43.110.149.187/model-assets/uing-original-23-20260929/2026-10-26-frozen-v1/all-23-models.zip)。公开范围仅限冻结清单中的这 23 件原始模型，不含未来新增训练资产或用户回传数据。SKILL 的 MIT 许可不覆盖模型；本次仅开放下载，不额外授予商用、再分发或模型训练许可。原始模型须分别检查，不代表全部通过抓取验收。
